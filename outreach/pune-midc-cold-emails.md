# Deliverability notes before sending

Same rules as before, worth repeating for a 14-email batch specifically:

1. **Don't send all 14 in one sitting from one inbox.** Space them out — 10-15/day if the mailbox isn't warmed up yet, more once it's established. A burst of 14 near-identical-looking emails to new recipients is exactly the pattern spam filters catch.
2. **Send individually**, not BCC'd or through a merge-mail blast tool without per-recipient personalization tracking.
3. **Plain text, no tracking pixels, no link shorteners.** Each draft above already has zero raw hyperlinks — keep it that way for the first touch.
4. **SPF/DKIM/DMARC on whatever domain sends these** — confirmed this matters more than copy quality. If not set up yet, this is worth doing before this batch goes out.
5. Recipient list is a mix of `sales@`, `purchase@`, `info@`, `enquiry@`, and one personal address (`jabbar.shaikh@nihalind.com`) — expect lower reply rates from the generic inboxes (they're often monitored loosely or by someone who isn't the decision-maker). If you can find a named contact (owner, plant head, maintenance head) at each company via LinkedIn, that'll outperform the generic inbox every time.
