# Q: Create a Pareto framework to reduce overinformation on the TurboFix public website

## Answer

Expanded via graph vocab: [content, marketing, public, website, customer, problem, value, outcome, proof, workflow, pricing, demo]. Recommendation: use a Decision-First Content framework combining Jobs-to-be-Done, StoryBrand, and progressive disclosure. Keep only one customer, one painful problem, three outcomes, one proof block, and one primary CTA in the main journey. Move feature lists, technical details, long workflow explanations, and most FAQs into secondary pages or expandable sections. Reduce primary navigation to Home, Product, How It Works, Pricing, and Book a Demo. Implement via inventory, scoring every block for relevance, differentiation, proof, and conversion, then rewriting and measuring CTA conversion.
