🚨 Common Issues & How to Fix

Problem: "I'm not seeing the new version"

Run this in browser console:

isFeatureFlagEnabled('use_refactored_machines')

If it returns false, your email isn't in the QA list. Ask tech team to add you.

If it returns true, try this:

setFeatureFlagOverride('use_refactored_machines', true)
window.location.reload()
Problem: "Page is slow"

Check DevTools Network tab:

  • Any failed requests? (red X)
  • Is a request taking > 5 seconds?
  • Take screenshot and report to tech team
Problem: "I see console errors (red messages)"

Take a screenshot and include:

  • Exact error message
  • What you were doing when it happened
  • Send to tech team for investigation
Problem: "A feature doesn't work"

Report with:

  • What you were trying to do
  • What actually happened
  • Screenshot if possible
  • Browser console errors (if any)
